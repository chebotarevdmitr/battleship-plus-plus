# 🚢 Battleship++

Классическая игра "Морской бой" на C++ с умным ИИ и возможностью сетевой игры.

## 🎯 Возможности

- 🎮 Консольная версия
- 🖥️ Графический интерфейс (Qt 6)
- 🤖 Умный ИИ с тремя уровнями сложности
- 🌐 Сетевая игра (планируется)
- 📱 Поддержка Android (планируется)

## 🛠️ Технологии

| Технология | Назначение |
|------------|------------|
| **C++20** | Основной язык |
| **CMake 4.2+** | Система сборки |
| **vcpkg** | Менеджер пакетов |
| **Qt 6** | Графический интерфейс |
| **Google Test** | Модульные тесты |
| **clang-tidy** | Статический анализ |
| **clang-format** | Форматирование кода |
| **Valgrind / perf** | Профилирование |
| **VSCode + clangd** | IDE |

## 🚀 Сборка проекта

### Требования

- Компилятор: `g++ 15+` или `clang++ 21+`
- `cmake 4.2+`
- `vcpkg` (с переменной окружения `VCPKG_ROOT`)
- `Qt 6` (для графической версии)

### Шаги сборки

```bash
# Клонирование репозитория
git clone <ссылка на репозиторий>
cd battleship-plus-plus

# Создание папки сборки и конфигурация
mkdir build && cd build
cmake -DCMAKE_TOOLCHAIN_FILE="$VCPKG_ROOT/scripts/buildsystems/vcpkg.cmake" ..

# Сборка
cmake --build .

# Запуск тестов
ctest --output-on-failure

# Запуск консольной версии игры
./battleship_cli
