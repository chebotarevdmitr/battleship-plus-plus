# 🚢 Battleship++

> 📚 **Учебный проект** для глубокого изучения современного C++20, архитектуры приложений, тестирования и работы с профессиональным инструментарием разработчика.

Классическая игра "Морской бой" с умным ИИ и возможностью сетевой игры по интернету.

## 🎯 Возможности

- 🎮 Консольная версия игры
- 🖥️ Графический интерфейс на Qt 6
- 🤖 Умный ИИ с тремя уровнями сложности
- 🌐 Сетевая игра по интернету (планируется)
- 📱 Поддержка Android (планируется)

## 🛠️ Технологии

## 🚀 Сборка проекта

### Требования

- Компилятор: `g++ 15+` или `clang++ 21+`
- `cmake 4.2+`
- `vcpkg` (с переменной окружения `VCPKG_ROOT`)
- `Qt 6` (для графической версии)

### Шаги сборки

```bash
# 1. Клонирование репозитория
git clone <ссылка на репозиторий>
cd battleship-plus-plus

# 2. Создание папки сборки и конфигурация
mkdir build && cd build
cmake -DCMAKE_TOOLCHAIN_FILE="$VCPKG_ROOT/scripts/buildsystems/vcpkg.cmake" ..

# 3. Сборка
cmake --build .

# 4. Запуск тестов
ctest --output-on-failure

# 5. Запуск консольной версии игры
./battleship_cli
