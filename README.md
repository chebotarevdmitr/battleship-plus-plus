# 🚢 Battleship++

> 📚 **Учебный open-source проект** для глубокого изучения современного C++20, архитектуры приложений, тестирования (TDD) и практик кибербезопасности при разработке ПО.

Классическая игра "Морской бой", которая развивается от простой консольной утилиты до защищённого кроссплатформенного сетевого приложения.

## 🎯 Особенности проекта

- 🎮 **Поэтапная разработка:** От консольной версии до графического интерфейса и мобильных платформ.
- 🤖 **Умный ИИ:** Противник с тремя уровнями сложности (от случайных выстрелов до вероятностного анализа поля).
- 🌐 **Сетевой режим:** Клиент-серверная архитектура с шифрованием трафика (планируется).
- 🛡️ **Акцент на безопасность:** Использование санитайзеров, статического анализа и защищённых практик кодирования (Secure Coding) на каждом этапе.
- 🧪 **Test-Driven Development (TDD):** Покрытие модульными тестами всей бизнес-логики.

## 🛠️ Технологический стек

Проект специально построен на использовании профессионального инструментария индустрии:

| Категория | Инструменты |
| :--- | :--- |
| **Язык и стандарт** | C++20 (с элементами C++23) |
| **Сборка и зависимости** | CMake 3.20+, `vcpkg` (или Conan) |
| **Компиляторы** | `g++` (GCC 11+) и `clang++` (Clang 15+) |
| **Тестирование** | Google Test (GTest), `gcov`/`lcov` (покрытие кода) |
| **Качество и безопасность** | `clang-tidy`, `cppcheck`, `clang-format`, AddressSanitizer (ASan), UndefinedBehaviorSanitizer (UBSan), Valgrind |
| **Графика и UI** | Qt 6 (или SFML как альтернатива) |
| **Сети** | Boost.Asio, OpenSSL (для TLS) |
| **Среда разработки** | VS Code, `clangd`, Git, GitHub Actions (CI/CD) |
| **Документация** | Doxygen, Markdown |

## 🛡️ Кибербезопасность в проекте

Поскольку проект имеет учебный уклон в InfoSec, в нём реализуются следующие практики:

1. **Защита памяти:** Обязательное использование умных указателей (`std::unique_ptr`, `std::shared_ptr`) и проверка кода через ASan/UBSan в CI.
2. **Статический анализ:** Интеграция `clang-tidy` и `cppcheck` для выявления уязвимостей (CWE Top 25) до компиляции.
3. **Безопасность сети:** Валидация всех входящих пакетов на стороне сервера, защита от replay-атак и использование шифрования (TLS).
4. **Anti-Cheat:** Логика игры вынесена на сервер; клиент получает только необходимую для отрисовки информацию.

## 🚀 Сборка и запуск (Ubuntu Linux)

### Требования

```bash
sudo apt update
sudo apt install build-essential cmake git clang clang-tidy clang-format gdb valgrind

# 1. Клонирование репозитория
git clone https://github.com/chebotarevdmitr/battleship-plus-plus.git
cd battleship-plus-plus

# 2. Создание папки сборки и конфигурация (с использованием vcpkg)
mkdir -p build && cd build
cmake -DCMAKE_BUILD_TYPE=Debug -DCMAKE_TOOLCHAIN_FILE="$VCPKG_ROOT/scripts/buildsystems/vcpkg.cmake" ..

# 3. Сборка проекта
cmake --build . -j$(nproc)

# 4. Запуск модульных тестов
ctest --output-on-failure

# 5. Запуск консольной версии игры
./battleship_cli

battleship-plus-plus/

📈 Roadmap (План развития)
Проект развивается итеративно, каждый этап завершается релизом с тегом в Git:

Этап 0: Фундамент. Настройка окружения, CMake, vcpkg, CI/CD, первые классы и тесты.
Релиз 1 (v1.0): Консольная игра. Полная логика игры, умный бот, случайная расстановка, 90%+ покрытие тестами, интеграция санитайзеров.
Релиз 2 (v2.0): Графика и мультимедиа. Переход на Qt 6 / SFML, анимации, звуки, ручная расстановка кораблей, паттерн Observer.
Релиз 3 (v3.0): Сетевая игра. Клиент-серверная архитектура (Boost.Asio), собственный бинарный протокол, шифрование трафика, защита от читов.
Релиз 4 (v4.0): Мобильная версия и полировка. Сборка под Android (NDK), адаптация UI, финальная оптимизация (perf), генерация документации (Doxygen).

🧪 Тестирование и качество
Проект следует принципам TDD. Перед каждым коммитом код проверяется на:
Корректность форматирования (clang-format)
Отсутствие статических предупреждений (clang-tidy)
Успешное прохождение всех unit-тестов (ctest)
Отсутствие утечек памяти и неопределенного поведения (через ASan/UBSan в Debug-режиме).
